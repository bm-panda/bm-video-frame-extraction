# 视频抽帧脚本

一键从视频中抽取关键画面为 PNG 图片，支持按秒、按帧间隔、指定时间点、关键帧、智能抽帧 5 种抽取方式，基于 FFmpeg 引擎，支持批量处理。

---

## 脚本简介

本工具提供一个简洁的图形配置界面，让您轻松配置抽取参数。配置完成后，在文件资源管理器中选中视频文件，右键即可一键完成抽帧。

---

## 核心特性

- **5 种抽取方式**：
  - **按秒抽帧**：每 N 秒抽一帧（如每 5 秒）
  - **固定间隔帧**：每 N 帧抽一帧（如每 30 帧）
  - **指定时间点**：在指定时间点抽帧（如 00:00:05、00:00:15）
  - **关键帧抽取**：只抽关键帧（I 帧）
  - **智能抽帧**：基于相似度去重，自动保留视觉上显著不同的画面（阈值可调 0.5~0.95），可捕捉幻灯片文字变化、只留睁眼帧、从指定时间点开始
- **右键菜单集成**：配置一次，永久生效。选中视频 → 右键 → 一键抽帧
- **惰性配置**：未配置时右键选中视频会自动弹出配置窗口引导设置，保存后立即开始抽帧，无需提前手动打开
- **批量处理**：支持同时选中多个视频文件批量抽帧
- **PNG 无损输出**：图片无损压缩，适合后续编辑
- **每视频一文件夹**：输出到 `<视频名>_frames` 子文件夹，多视频不混淆
- **自定义输出目录**：可指定输出位置，留空则在视频所在目录下建子文件夹
- **智能跳过**：已存在的输出自动跳过（可开启覆盖）
- **实时进度**：抽帧过程中实时显示百分比与已处理时长

## 安装方法

* 通过不忙脚本盒子安装（推荐）
  
  * 下载并安装 [不忙脚本盒子](https://www.bm-box.cn)
  
  * 打开不忙脚本盒子 → **脚本市场** → 搜索 **「视频抽帧」**
  
  * 点击「安装」

* 手动运行（有编程基础用户）
  
      # 1. 安装 FFmpeg（ffmpeg 命令需在 PATH 中可用）
      # 2. 配置python环境
      uv venv
      uv sync
      # 3. 启动脚本
      python main.py                # 启动配置界面（无参数）
      python main.py <参数JSON路径>  # 带参数启动（用于右键调用）

✅ 推荐使用不忙脚本盒子安装、盒子会自动为脚本配置环境、并提供右键、快捷键执行脚本的能力

## 启动方式

通过不忙脚本盒子安装后，可通过以下方式使用「视频抽帧」功能：

* 配置参数（首次使用或需修改配置时）
  
  * 打开「不忙脚本盒子」
  
  * 点击「视频抽帧」进入配置窗口
  
  * 根据需求设置转换参数
  
  * 点击「保存配置」

* 执行视频抽帧（日常使用）
  
  * 在文件管理器中选中视频文件
  
  * 右键点击，选择「视频抽帧」
  
  * 脚本自动按保存的配置执行视频抽帧（未配置过时会先弹出配置窗口，保存后立即抽帧）

* 快捷键操作
  
  * 为脚本设置全局快捷键
  
  * 选中视频后按下快捷键即可快速执行

✅ 配置保存后永久生效，无需每次重复设置

🔄 仅在需要更改参数时才需重新进入配置窗口

## 💡 使用提示

- **按秒抽帧**：适合制作缩略图、快速浏览视频内容
- **智能抽帧**：与上一张已保留画面比较相似度，相似则跳过、显著不同才保存，能跨相似片段自动去重。**阈值越高保留帧越多**（0.95 几乎每个变化都保留，0.5 只留差别很大的画面）
  - **检测幻灯片文字变化(refine)**：直方图会漏掉"画面静止但标题/文字变了"的场景，勾选后用 HOG/ORB 复核可捕捉（如 PPT）
  - **仅保留睁眼帧**：只保存检测到有人睁眼的画面（适合访谈/录课）
  - **起始时间**：从指定秒数开始抽取，留空从头开始
- **关键帧抽取**：只输出 I 帧，数量取决于编码间隔，通常远小于总帧数
- **输出位置**：默认在视频所在目录下建 `<视频名>_frames` 文件夹，指定输出目录后在其下建文件夹
- **覆盖说明**：默认跳过已存在的输出文件夹，勾选「覆盖已存在的文件」后会清空旧图重新抽取
